Purpose & Scope Slide 2
  • Provides a secure, role-based authentication and authorization system for the Placement Operations Management System (POMS) [cite: 1].
  • Ensures every user accesses only the modules and features required for their responsibilities while maintaining data security [cite: 1].
  • Authenticates all users securely and provides strict role-based access control (RBAC) across all modules [cite: 1].
  • Maintains accurate, auditable user information and tracks login activity and session history [cite: 1].
User Roles & Responsibilities Slide 3

Placement Coordinator [cite: 1]

Operational user responsible for company outreach and daily placement activities [cite: 1]. Maintains the daily tracker and manages positive leads [cite: 1].

Team Leader [cite: 1]

Operational supervisor responsible for monitoring multiple coordinators [cite: 1]. Verifies data, manages the company database, and monitors reports [cite: 1].

Administrator (CEO / Director) [cite: 1]

System owner with unrestricted administrative privileges [cite: 1]. Handles user management, system configuration, and data security [cite: 1].

Training & Placement Officer (TPO) [cite: 1]

Read-only external stakeholder responsible for monitoring placement activities [cite: 1]. Views placement statistics, weekly reports, and dashboards [cite: 1].

Key Architecture & Security Rules Slide 4
  • Unified Login: A single login screen serves all roles, automatically redirecting the user to their respective dashboard after authentication [cite: 1].
  • Data Classification: Company data is securely split into Protected Master Information (editable by Admins/TLs) and Operational Contact Information (editable by Coordinators) [cite: 1].
  • Account Lifecycle: Accounts hold exactly one status at a time: Active, Inactive, On Leave, or Resigned [cite: 1]. Historical data is retained for audit continuity [cite: 1].
  • Security Matrix: Passwords are encrypted at rest, role-based authorization is enforced on every request, and every login attempt is recorded [cite: 1].
